# Analytics Aggregators Tests

Тесты для проверки корректности расчетов в агрегаторах аналитики.

## Цель

Убедиться, что AI получает правильные цифры:
- ✅ winRate рассчитывается корректно
- ✅ avgDealValue рассчитывается корректно  
- ✅ profit и profitMargin рассчитываются корректно
- ✅ duplicates count работает правильно
- ✅ timezone Asia/Jerusalem корректно фильтрует период

## Запуск тестов

### Простой скрипт (рекомендуется)

```bash
npx tsx lib/analytics/__tests__/test-calculations.ts
```

Или если tsx не установлен:

```bash
npm install -D tsx
npx tsx lib/analytics/__tests__/test-calculations.ts
```

### С Jest (если установлен)

```bash
npm install -D jest @types/jest ts-jest
npm test
```

## Что тестируется

### 1. winRate
- Расчет процента завершенных сделок
- Обработка пустых данных
- Правильное округление

### 2. avgDealValue
- Средняя стоимость сделки
- Исключение null/0 значений
- Правильное округление

### 3. profit и profitMargin
- Выручка из завершенных сделок
- Затраты на труд из work_shifts
- Расчет прибыли и маржи
- Обработка отрицательной прибыли

### 4. duplicates count
- Подсчет дубликатов по телефону
- Правильная группировка
- Обработка уникальных записей

### 5. Timezone filtering
- Конвертация дат в UTC
- Правильные границы периода (00:00:00 - 23:59:59)
- Корректная работа с Asia/Jerusalem

### 6. Edge cases
- Пустые массивы
- Null/undefined значения
- Нулевые значения
- Отрицательные числа

## Тестовые данные

Тесты используют фиктивные данные:
- 4 сделки (2 завершены, 2 активны)
- 3 лида (1 дубликат по телефону)
- 3 смены работников

## Результаты

При успешном прохождении всех тестов:
```
✅ All tests passed!
📊 Calculations are correct - AI will receive accurate data.
```

При ошибке тест остановится и покажет детали проблемы.
