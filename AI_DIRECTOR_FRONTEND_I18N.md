Изменения:

---

## 🎯 Как это работает:

### Переключение языка:

1. **В сайдбаре CRM** есть переключатель языков (уже существует)
2. При выборе языка весь интерфейс **автоматически переключается**
3. Язык сохраняется в `localStorage` (ключ: `crm_language`)

### Поддерживаемые элементы:

| Элемент | EN | HE | RU |
|---------|----|----|-----|
| Заголовок | AI Business Director | AI-מנהל עסקי | AI-директор по бизнес-решениям |
| Подзаголовок | Ask questions about your business... | שאל שאלות על העסק שלך... | Задайте вопрос о вашем бизнесе... |
| Placeholder | Ask the AI Director... | שאל את ה-AI מנהל... | Спросите AI-директора... |
| Кнопка отправки | Send | שלח | Отправить |
| Загрузка | AI Director is thinking... | ה-AI מנהל חושב... | AI-директор думает... |
| Примеры вопросов | ✅ | ✅ | ✅ |
| Футер | ✅ | ✅ | ✅ |

## 🔧 Добавление новых языков:

Если нужно добавить новый язык (например, арабский):

### 1. Обновите `apps/crm/lib/translations/ai-director.ts`:

```typescript
export const aiDirectorTranslations = {
  // ... existing translations ...
  ar: {
    title: 'مدير الأعمال الذكي',
    subtitle: 'اطرح أسئلة حول عملك واحصل على توصيات استراتيجية',
    placeholder: 'اسأل مدير الذكاء الاصطناعي عن عملك...',
    send: 'إرسال',
    // ... etc
  }
}
```

### 2. Обновите `apps/crm/lib/language-context.tsx`:

```typescript
type Language = 'he' | 'ru' | 'en' | 'ar'
```

### 3. Добавьте в `LanguageSwitcher` новую опцию

## 🎨 RTL (Right-to-Left) поддержка:

Для языков с направлением справа налево (иврит, арабский):

```typescript
const isRTL = language === 'he' || language === 'ar'

<div className={isRTL ? 'rtl' : 'ltr'}>
  <textarea dir={isRTL ? 'rtl' : 'ltr'} />
</div>
```
