# ✅ Интеграция הצעת מחיר в Deals - Готово!

## Что добавлено в DealModal:

### 1. Кнопка "יצירת הצעת מחיר"
- Расположена рядом с кнопкой эскиза
- Зеленая кнопка с иконкой FileText
- Открывает модальное окно создания предложения

### 2. Список предложений
- Показывается под кнопками
- Автоматически обновляется после создания нового предложения
- Отображает все предложения для данной сделки

## Как это работает:

1. **Откройте сделку** в админке (клик на карточку deal)
2. **Нажмите "יצירת הצעת מחיר"** (зеленая кнопка)
3. **Заполните форму**:
   - Размеры пергулы (width, length, height)
   - Цены за м² (редактируемые)
   - Включить/выключить сантаф
   - Выбрать тип сантафа
   - Указать скидку %
4. **Нажмите "שמור הצעת מחיר"**
5. **Предложение создано** и появится в списке

## Структура данных:

```typescript
// Offer связан с Deal через deal_id
interface Offer {
  id: string
  dealId: string  // ← связь с deal.id
  customerName: string
  customerPhone?: string
  width: number
  length: number
  height?: number
  // ... prices and calculations
  finalPrice: number
  approved: boolean
  createdAt: string
}
```

## Что показывается в модалке:

### Информация о клиенте (read-only):
- Имя (из deal.customer_name)
- Телефон (из deal.customer_phone)
- Город (из deal.customer_city)

### Форма предложения:
- Размеры пергулы
- Цены (редактируемые)
- Сантаф (опционально)
- Скидка
- **Автоматический расчет всех цен**

### Список предложений:
- Все предложения для данной сделки
- Размеры и финальная цена
- Статус (ממתין לאישור / אושר)
- Дата создания

## API Endpoints:

```typescript
// Создать предложение
POST /api/offers
Body: { dealId, customerName, width, length, ... }

// Получить предложения сделки
GET /api/offers?dealId=xxx
```
