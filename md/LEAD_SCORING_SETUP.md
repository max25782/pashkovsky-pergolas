# AI Lead Scoring Setup Guide

## Описание

AI Lead Scoring — гибридная система оценки качества лидов, сочетающая детерминированные правила и AI корректировку.

## Архитектура

### Гибридный подход:
1. **Правила (deterministic)** — базовый score 0-100
2. **AI корректировка** — максимум +/-10 от базового score
3. **Итоговый score** — ruleScore + aiDelta (0-100)

### Категории:
- **Hot (80-100)**: Горячие лиды, требуют немедленного внимания
- **Warm (50-79)**: Нормальные лиды, стандартная обработка
- **Cold (<50)**: Слабые лиды, низкий приоритет

## Правила скоринга (Rule-based)

### Источник (0-25 баллов):
- Facebook: 20
- Google: 18
- Site: 15
- Leadconnector: 12
- Instagram: 10
- WhatsApp: 8
- Referral: 15
- Другое: 5

### Контактная информация (0-30 баллов):
- Телефон (полный): +10
- Имя: +10
- Город: +5
- Email: +5

### Качество сообщения (0-20 баллов):
- Подробное описание (>100 символов): +20
- Есть описание (50-100 символов): +10
- Короткое описание: +5
- Нет описания: 0

### Статус (0-15 баллов):
- Won: +20
- Qualified: +15
- Confirmed: +12
- Contacted: +8
- Pending: +3
- Lost: -10

### Актуальность (0-10 баллов):
- Создан сегодня: +10
- Создан вчера: +8
- 2-3 дня назад: +5
- 4-7 дней назад: +2
- Старше 7 дней: 0

### Время ответа (0-10 баллов):
- <1 часа: +10
- <4 часов: +7
- <24 часов: +4
- >24 часов: 0

### Штрафы:
- Дубликат (такой же телефон): -15

### Бонусы:
- Есть вложения/фото: +5

## AI Корректировка

AI анализирует контекст лида и может скорректировать score максимум на +/-10 баллов.

### Что анализирует AI:
- Полнота данных
- Качество описания
- Контекстные факторы
- Рекомендации по следующим шагам

### Ограничения:
- AI не может изменить score больше чем на +/-10
- AI работает только с переданными данными
- Не придумывает факты

## API Endpoints

### 1. Score single lead

```
POST /api/leads/[id]/score
Headers: x-admin-token: YOUR_ADMIN_TOKEN
```

Response:
```json
{
  "finalScore": 85,
  "ruleScore": 80,
  "aiDelta": 5,
  "reasons": ["Источник facebook: +20 баллов", ...],
  "aiReasons": ["Качественное описание проекта", ...],
  "suggestedNextAction": "Позвонить в течение 10 минут"
}
```

### 2. Batch score leads

```
POST /api/leads/score/batch?period=last30days
Headers: x-admin-token: YOUR_ADMIN_TOKEN
```

Query params:
- `period`: `last7days` или `last30days`

Response:
```json
{
  "success": true,
  "period": { "from": "2024-01-01", "to": "2024-01-31" },
  "total": 100,
  "scored": 98,
  "failed": 2,
  "results": [...]
}
```

## UI

### Список лидов

Добавлена колонка "Score" с форматом:
- `92 (Hot)`
- `64 (Warm)`
- `30 (Cold)`
- `-` (если score не рассчитан)

### Страница лида

Блок "AI Score" показывает:
- Итоговый score и категорию
- Разбивку (ruleScore + aiDelta)
- Причины от правил
- Причины от AI
- Рекомендацию по следующему шагу
- Кнопку "Пересчитать"

## Использование

### Ручной скоринг

1. Откройте лид в модальном окне
2. Нажмите "Рассчитать" или "Пересчитать" в блоке AI Score
3. Просмотрите результаты и рекомендации

### Массовый скоринг

1. Вызовите API endpoint `/api/leads/score/batch?period=last30days`
2. Дождитесь завершения обработки
3. Проверьте результаты в списке лидов

## Troubleshooting

### Score не рассчитывается

1. Проверьте, что миграция выполнена
2. Убедитесь, что есть данные в таблице leads
3. Проверьте логи API

### AI не работает

1. Проверьте переменную окружения `GEMINI_API_KEY`
2. Убедитесь, что API доступен
3. Проверьте логи ошибок

### Неправильные scores

1. Проверьте правила скоринга в `lib/leads/scoring.ts`
2. Убедитесь, что данные лида корректны
3. Проверьте логи AI ответов
