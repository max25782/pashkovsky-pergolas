# Тестирование поддомена CRM на localhost

## Шаг 1: Добавить запись в hosts файл (Windows)

1. Откройте **Блокнот** от имени администратора:
   - Нажмите `Win + S`
   - Введите "Блокнот"
   - Правой кнопкой → **Запуск от имени администратора**

2. Откройте файл hosts:
   - Файл → Открыть
   - Перейдите в: `C:\Windows\System32\drivers\etc\`
   - Внизу справа выберите "Все файлы (*.*)"
   - Откройте файл `hosts`

3. Добавьте в конец файла:
   ```
   127.0.0.1 crm.localhost
   ```

4. Сохраните файл (Ctrl+S)

## Шаг 2: Запустить dev server

```powershell
npm run dev
```

Сервер запустится на `http://localhost:3000`

## Шаг 3: Проверить работу

### Основной домен (должен работать как обычно):
- ✅ `http://localhost:3000` → главная страница
- ✅ `http://localhost:3000/he` → главная страница (Hebrew)
- ✅ `http://localhost:3000/he/admin/deals` → редирект на `crm.localhost:3000/admin/deals`

### Поддомен CRM (должен показывать админку):
- ✅ `http://crm.localhost:3000` → редирект на `/admin/deals`
- ✅ `http://crm.localhost:3000/admin/deals` → админка CRM
- ✅ `http://crm.localhost:3000/he` → редирект на `/admin/deals`
- ✅ `http://crm.localhost:3000/he/admin/deals` → админка CRM

## Проверка через PowerShell

Можно проверить, что hosts файл работает:

```powershell
# Проверить разрешение DNS
nslookup crm.localhost
```

Должен показать `127.0.0.1`

## Если не работает

1. **Очистите DNS кэш:**
   ```powershell
   ipconfig /flushdns
   ```

2. **Перезапустите браузер** (полностью закройте и откройте заново)

3. **Проверьте, что hosts файл сохранен правильно:**
   - Убедитесь, что файл сохранен как `hosts` (без расширения `.txt`)
   - Убедитесь, что нет лишних пробелов в конце строки

4. **Проверьте, что dev server запущен:**
   ```powershell
   # Должен быть процесс на порту 3000
   netstat -ano | findstr :3000
   ```

## Альтернативный способ (без hosts файла)

Если не хотите редактировать hosts файл, можно использовать другой порт для CRM:

1. Запустите второй экземпляр на другом порту:
   ```powershell
   # Терминал 1 - основной сайт
   npm run dev
   
   # Терминал 2 - CRM (если нужно)
   $env:PORT=3001; npm run dev
   ```

2. Но лучше использовать поддомен через hosts файл - это ближе к production.

## Быстрая проверка

После настройки hosts файла и запуска dev server:

1. Откройте `http://crm.localhost:3000`
2. Должен быть редирект на `/admin/deals`
3. Должна открыться страница админки CRM

Если видите главную страницу вместо админки - проверьте:
- Правильно ли добавлена запись в hosts
- Перезапущен ли браузер
- Запущен ли dev server
