# Система управления закрытыми лидами (Deals)

## Описание

Когда лид в простой CRM получает статус "won" (закрыт), он автоматически переносится в новую таблицу `deals` - более сложную CRM систему для управления проектами и сделками.

## Структура базы данных

### Таблица `deals`

Создана таблица с расширенными полями для управления проектами:

- **Базовая информация**: имя, телефон, email, город клиента
- **Информация о сделке**: статус, тип проекта, адрес, описание
- **Финансовая информация**: общая сумма, депозит, финальная сумма, статус оплаты
- **Даты**: дата сделки, подтверждения, начала производства, завершения, доставки, установки
- **Детали проекта**: конфигурация (JSON), материалы (JSON), измерения (JSON)
- **Коммуникация**: заметки, внутренние заметки, лог коммуникаций
- **Назначение команды**: менеджер по продажам, менеджер проекта, установщик
- **Отслеживание источника**: исходный источник лида, реферальный источник

## API Endpoints

### GET `/admin-api/deals`
Получить список сделок с фильтрацией:
- `q` - поиск по имени, телефону, адресу, заметкам
- `status` - фильтр по статусу сделки
- `deal_type` - фильтр по типу сделки
- `payment_status` - фильтр по статусу оплаты
- `start_date`, `end_date` - фильтр по дате
- `limit`, `offset` - пагинация

### POST `/admin-api/deals`
Создать новую сделку. Можно передать `lead_id` для автоматического заполнения данных из лида.

### PATCH `/admin-api/deals`
Обновить сделку. Передать `id` и поля для обновления.

### DELETE `/admin-api/deals?id=...`
Удалить сделку.

## Автоматический перенос лидов

Когда статус лида меняется на "won" через API `/admin-api/leads` (PATCH), автоматически:
1. Создается запись в таблице `deals`
2. Данные лида копируются в сделку
3. Email и город извлекаются из поля `notes` лида
4. Создается связь через `lead_id`

## Использование

### Пример создания сделки из лида:
```javascript
// Когда лид получает статус "won", автоматически создается deal
PATCH /admin-api/leads
{
  "id": "lead-uuid",
  "status": "won"
}
```

### Пример создания сделки вручную:
```javascript
POST /admin-api/deals
{
  "lead_id": "lead-uuid", // опционально
  "customer_name": "Иван Иванов",
  "customer_phone": "+972501234567",
  "deal_type": "pergola",
  "total_amount": 50000,
  "project_address": "Тель-Авив, ул. Пример, 1"
}
```

### Пример получения списка сделок:
```javascript
GET /admin-api/deals?status=in_progress&limit=20
```
