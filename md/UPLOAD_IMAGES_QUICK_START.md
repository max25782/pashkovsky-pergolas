## 🔧 Техническое объяснение

### Что было исправлено:

#### **Проблема:**
- Next.js 14 кеширует все API routes по умолчанию
- API не сортировал картинки по дате
- Новые картинки не появлялись на сайте

#### **Решение:**
```typescript
// app/api/gallery/images/route.ts

// 1. Отключили кеш Next.js
export const dynamic = 'force-dynamic'
export const revalidate = 0

// 2. Добавили сортировку по дате
.order('created_at', { ascending: false })

// 3. Добавили Cache-Control headers
'Cache-Control': 'no-store, no-cache, must-revalidate, max-age=0'
```
