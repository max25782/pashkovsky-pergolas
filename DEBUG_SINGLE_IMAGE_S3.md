# 🔍 Диагностика: Одно изображение не загружается из S3

## Что нужно проверить

### 1. Откройте консоль браузера (F12)

Проверьте:
- Есть ли ошибка 404 для конкретного изображения?
- Какой URL изображения не загружается?
- В каком компоненте это происходит?

### 2. Проверьте Network tab

1. Откройте DevTools → Network
2. Обновите страницу
3. Найдите запрос с ошибкой (красный статус)
4. Посмотрите URL этого запроса

### 3. Проверьте логи сервера

Если используете API endpoint для загрузки изображений, проверьте логи:
- `/api/gallery/models`
- `/api/gallery/[category]`
- Другие API endpoints

---

## Возможные причины

### 1. Изображение отсутствует в S3

**Решение:** Загрузите изображение в S3 bucket по правильному пути.

### 2. Неправильный путь в коде

**Решение:** Проверьте путь к изображению в JSON файлах или компонентах.

### 3. Проблема с правами доступа

**Решение:** Проверьте что файл публично доступен в S3.

### 4. Регион S3 не совпадает

**Решение:** Убедитесь что `NEXT_PUBLIC_AWS_S3_REGION` правильный.

---

## Как найти проблемное изображение

### Вариант 1: Через консоль браузера

Откройте консоль и выполните:

```javascript
// Найти все изображения которые не загрузились
document.querySelectorAll('img').forEach(img => {
  img.addEventListener('error', () => {
    console.error('Failed image:', img.src)
  })
})
```

### Вариант 2: Проверить Network tab

1. Откройте DevTools → Network
2. Фильтр: `Img`
3. Найдите запросы с ошибкой (красные)
4. Посмотрите URL

---

## Быстрое решение

Если знаете какое изображение не загружается:

1. **Проверьте путь в коде:**
   - Найдите где используется это изображение
   - Проверьте путь в JSON файлах (`data/gallery/*.json`)
   - Проверьте что путь правильный

2. **Проверьте наличие в S3:**
   - Откройте AWS S3 Console
   - Найдите файл по пути
   - Убедитесь что файл существует

3. **Проверьте URL формирование:**
   - Откройте консоль браузера
   - Найдите URL изображения
   - Проверьте что он правильный
