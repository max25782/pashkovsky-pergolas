# Как использовать Vim в интерактивном rebase (Mac Terminal)

## Когда откроется редактор

После выполнения `git rebase -i HEAD~4` откроется редактор vim с примерно таким содержимым:

```
pick f8c9312 fix s3
pick a20e42c profiles
pick 66b598f secret
pick 19fdd9b secret
pick cdbf09b fix: replace AWS credentials with placeholders

# Rebase f8c9312..cdbf09b onto f8c9312 (4 commands)
# ...
```

## Шаг 1: Перейти в режим редактирования

1. Нажмите `i` (insert mode) - внизу появится `-- INSERT --`

## Шаг 2: Изменить строку

1. Используйте стрелки ↑↓ чтобы найти строку: `pick a20e42c profiles`
2. Переместите курсор на букву `p` в слове `pick`
3. Удалите `pick` (нажмите `x` 4 раза или `dw` для удаления слова)
4. Введите `edit` вместо `pick`
5. Должно получиться: `edit a20e42c profiles`

## Шаг 3: Сохранить и выйти

1. Нажмите `Esc` (чтобы выйти из режима редактирования)
2. Введите `:wq` (двоеточие, затем wq)
3. Нажмите `Enter`

## Альтернатива: Использовать nano вместо vim

Если vim сложен, можно настроить git использовать nano:

```bash
# Установить nano как редактор по умолчанию для git
git config --global core.editor "nano"

# Затем повторить rebase
git rebase -i HEAD~4
```

В nano:
- Используйте стрелки для навигации
- Измените `pick` на `edit`
- Нажмите `Ctrl+X` (выход)
- Нажмите `Y` (подтвердить сохранение)
- Нажмите `Enter`

## Быстрые команды Vim

- `i` - войти в режим редактирования (insert mode)
- `Esc` - выйти из режима редактирования
- `:wq` - сохранить и выйти (write and quit)
- `:q!` - выйти без сохранения (quit without saving)
- `x` - удалить символ под курсором
- `dw` - удалить слово
- Стрелки ↑↓←→ - перемещение курсора

## Если что-то пошло не так

Если вы случайно что-то сломали в редакторе:
1. Нажмите `Esc`
2. Введите `:q!` и нажмите `Enter` (выйти без сохранения)
3. Начните заново: `git rebase -i HEAD~4`
